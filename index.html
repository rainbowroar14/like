Towny Town

Pygame wave-survival game. A normal index.html cannot run Python by itself — the playable web build is created with pygbag (WebAssembly).

One-time: create the web build

Windows: double-click build_web.bat, then serve_web.bat to test in the browser.

  1. Install Python 3.11+ and pip.
  2. From this folder (where main.py lives):
    pip install pygbag
pygbag --build --title "Towny Town" .
  3. Pygbag writes the real game page under build/web/ (many files + its own index.html).

Put it on a website

  • GitHub Pages / Netlify / Cloudflare: upload the contents of build/web/ (not the whole repo). The entry file will be pygbag’s index.html.
  • This file: optional landing page. The iframe below loads build/web/index.html if that folder exists next to this file.

Play (iframe)

If you see a blank frame, run the build commands above first. For hosting, you usually deploy build/web/ as the site root and can delete this landing page.
